# LTspice 符号引脚坐标参考（手工写 .asc 必备）

手工编写 `.asc` 原理图时，**导线端点必须精确落在元件引脚上**才算电气连接。
每个符号（`.asy`）定义了引脚相对放置点 `SYMBOL <name> X Y R0` 的偏移。
下表是常用符号在 **R0（不旋转）** 时的引脚坐标（绝对坐标 = 放置点 + 偏移）。

> 来源：`%LOCALAPPDATA%\LTspice\lib\sym\*.asy`。若版本不同，可自行读取对应 `.asy` 里的 `PIN x y` 行核对。

| 符号 | Prefix | 引脚（SpiceOrder 顺序）| 偏移 (dx, dy) |
|------|--------|------------------------|----------------|
| `voltage` | V | + (1) / − (2) | (0,16) / (0,96) |
| `current` | I | 流出(1) / 流入(2) | (0,16) / (0,96) |
| `res` 电阻 | R | A(1) / B(2) | (16,16) / (16,96) |
| `cap` 电容 | C | A(1) / B(2) | (16,0) / (16,64) |
| `ind` 电感 | L | A(1) / B(2) | (16,16) / (16,96) |
| `ind2` 电感(带相位点) | L | A(1) / B(2) | (16,16) / (16,96) |
| `diode` 二极管 | D | +阳(1) / −阴(2) | (16,0) / (16,64) |
| `sw` 压控开关 | S | A(1) / B(2) / NC+(3) / NC−(4) | (0,16) / (0,96) / (−48,80) / (−48,32) |
| `nmos` / `pmos` (4脚) | M | D / G / S / B | 视符号而定，用前先读 .asy |

## 旋转后的引脚换算
放置 `SYMBOL name X Y <rot>`，引脚绝对坐标按下式（(px,py) 为 R0 偏移）：

| 旋转 | 绝对坐标 |
|------|----------|
| R0   | (X+px, Y+py) |
| R90  | (X−py, Y+px) |
| R180 | (X−px, Y−py) |
| R270 | (X+py, Y−px) |
| M0   (水平镜像) | (X−px, Y+py) |
| M90/M180/M270 | 镜像后再旋转，建议放好后在 GUI 里核对 |

**常用技巧**：二极管默认 R0 是"阳上阴下、箭头朝下"。要让箭头朝上（阴极在上，如高边体二极管、整流管接正输出），用 **R180**：此时 +阳极在 (X−16, Y)、−阴极在 (X−16, Y−64)。

## .asc 文件结构速查
```
Version 4
SHEET 1 <w> <h>
WIRE x1 y1 x2 y2          ; 一段导线
FLAG x y <netname>        ; 节点标号；netname=0 即接地符号
SYMBOL <name> X Y <rot>   ; 放元件
WINDOW 3 dx dy Left <sz>  ; (可选) 移动 Value 文本位置，避免标签重叠
SYMATTR InstName R1       ; 元件名
SYMATTR Value 100         ; 参数值（开关填 model 名，电压源填 PULSE(...) 等）
TEXT x y Left 2 !<spice>  ; SPICE 指令（!开头），多条用 \n 连接
TEXT x y Left 2 ;<note>   ; 注释（;开头）
```

## 连线两条等价方式
1. **画真实导线**：`WIRE` 段端点落在引脚坐标上 → 直观、像教科书图，但布线易出错。
2. **网络标号**：在引脚坐标放 `FLAG x y NAME`，相同 NAME 自动相连 → 零布线错误、节点名清晰。

**推荐流程**：先用方式 2 保证电气正确并 Run 验证 → 再按需替换成方式 1 求美观。
两版都应能跑出相同波形，这是"接线正确"的硬标准。
