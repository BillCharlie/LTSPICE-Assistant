## 1. 整体概览

这是一个**半桥 LLC 谐振变换器**，把 400V 直流母线变换成约 48V/96W 的稳定输出。核心思想：用一个 LC 谐振网络，让开关管的电压/电流在过零点附近切换，从而几乎消除开关损耗。

| 设计指标 | 数值 |
|----------|------|
| 输入电压 Vin | 400 V |
| 输出电压 Vout | ≈ 48.6 V |
| 输出功率 | ≈ 96 W |
| 开关频率 fsw | 132 kHz |
| 谐振频率 fr | 132.6 kHz |
| 工作点 | fsw ≈ fr（谐振点，增益≈1） |

## 2. 电路原理：LLC 为什么这样工作

### 2.1 名字的由来：两个 L、一个 C
LLC 谐振腔由三个元件构成：

- **Lr = 60µH**：谐振电感（串联）
- **Cr = 24nF**：谐振电容（串联）
- **Lm = 300µH**：励磁电感（即变压器原边电感，并联在变压器两端）

它比传统"LC 串联谐振"多了一个并联的 Lm，因此有 **两个谐振频率**：

```
串联谐振频率（只有 Lr、Cr 参与，副边带载时）：
  fr  = 1 / (2π·√(Lr·Cr))   = 1/(2π·√(60µ×24n)) ≈ 132.6 kHz

并联谐振频率（Lm 也参与，副边空载/电流断续时）：
  fp  = 1 / (2π·√((Lr+Lm)·Cr)) = 1/(2π·√(360µ×24n)) ≈ 54.2 kHz
```

实际工作频率总是在 `fp < fsw` 区间内移动，通过**调频**来调输出电压。

### 2.2 调频调压（增益曲线）
LLC 不靠占空比调压，而是**靠频率**：

| 工作区 | 频率 | 增益 M=Vout·n/(Vin/2) | 特点 |
|--------|------|------------------------|------|
| 容性区 | fsw > fr | < 1（降压） | 失去 ZVS，应避免 |
| **谐振点** | **fsw = fr** | **= 1** | **最佳点，本电路所在** |
| 感性区 | fp < fsw < fr | > 1（升压） | 仍保持 ZVS，正常调压区 |

本电路把 fsw 设在 fr（132kHz），增益≈1，因此：
```
Vout ≈ (Vin/2) / n = 200 / 4 = 50 V   （实测 48.6V，差值来自二极管压降）
```

### 2.3 为什么要谐振？——为了软开关
谐振网络让流过开关管的电流变成**正弦**而非方波。配合死区时间，开关管可以：
- **开通时**两端电压已被拉到 0（ZVS，零电压开通）
- 副边二极管**关断时**电流已自然过零（ZCS，零电流关断）

这就是 LLC 高效率、低 EMI 的根本原因。详见第 7 节。

## 3. 电路架构：五大模块

电流从输入到输出，依次经过 5 个模块：

```
 ① 输入源        ② 半桥逆变         ③ 谐振腔          ④ 变压器      ⑤ 整流滤波
┌────────┐    ┌──────────┐    ┌────────────┐   ┌────────┐   ┌──────────────┐
│ Vin    │    │ S1 (上管) │    │ Cr 谐振电容 │   │  4:1   │   │ D1~D4 全桥整流│
│ 400V   │───>│ S2 (下管) │──> │ Lr 谐振电感 │──>│ Lp//Ls │──>│ Co 47µF       │──> 48V
│  DC    │    │ +体二极管 │    │ Lm 励磁电感 │   │ K=0.999│   │ Rload 25Ω     │
└────────┘    └──────────┘    └────────────┘   └────────┘   └──────────────┘
                  SW节点          200V直流偏置                   D1/D4 或 D2/D3
```

| 模块 | 元件 | 作用 |
|------|------|------|
| ① 输入 | `Vbus` | 400V 直流母线 |
| ② 半桥 | `S1/S2`（理想开关）+ `Dhs/Dls`（体二极管）+ `Coss1/2`（结电容） | 把直流斩成 0/400V 方波（SW 节点），体二极管提供 ZVS 续流 |
| ③ 谐振腔 | `Cr` `Lr` `Lp(=Lm)` | 把方波整形成正弦电流；Cr 同时隔直、承担 Vin/2 直流偏置 |
| ④ 变压器 | `Lp` `Ls`（`K1` 耦合，匝比 4:1） | 隔离、降压；Lp 兼作励磁电感 |
| ⑤ 整流 | `D1~D4` 全桥 + `Co` + `Rload` | 把副边交流整成直流；Co 滤波 |

> **关键点**：谐振电容 Cr 上的直流电压实测 **201V = Vin/2**。因为 Cr 隔直，SW 节点平均电压是 Vin/2，而原边 Lp 底端接地（平均 0V），所以 Cr 必须顶住这 200V 直流差，叠加 ±谐振交流后在 **114V~286V** 之间摆动。

## 4. 为什么画了两组电路

我提供了**两个 `.asc` 原理图文件**，它们描述的是**同一个电路**，只是"连线方式"不同：

| 文件 | 连接方式 | 优点 | 适合 |
|------|----------|------|------|
| `LLC_converter.asc` | **网络标号版**：每个引脚贴一个节点名（VIN/SW/NA…），相同名字即相连 | 零布线错误、节点名一目了然 | 快速、复杂电路、工程师习惯 |
| `LLC_converter_wired.asc` | **全导线版**：用真实导线把元件连起来 | 直观、像教科书电路图 | 教学、人眼阅读 |

**为什么要两版？**
1. **先用标号版保证正确**：手工画 `.asc` 时，导线端点必须精确落在元件引脚坐标上，否则会"看着连上其实断开"。标号版避开了复杂布线，先确保电气 100% 正确。
2. **再做全导线版求好看**：在标号版验证无误的基础上，把节点标号替换成真实导线，得到美观的教科书式电路图。
3. **两版都用 Run 验证**：分别仿真，得到的 V(sw)/I(Lr)/V(vout) 与原网表**完全一致**，证明两版电气等价、接线都对。

> 一句话：标号版是"工程草图"，全导线版是"出版用图"，内核是同一个经过验证的电路。

## 5. 一个开关周期的四个状态 + 电流路径（核心）

一个开关周期 Tsw = 7.576µs 分为 **4 个阶段**：S1 导通 → 死区1 → S2 导通 → 死区2。
下面结合仿真实测，逐个分析**电流实际怎么流**。

约定：原边谐振电流 `iLr` 正方向 = 从 Vin 经 S1 流入谐振腔；下图用 `══>` 表示电流方向。

---

### 状态 ①　S1 导通（高边，0 ~ 3.59µs）　SW = 400V

上管 S1 闭合，SW 接到 400V。母线电压减去 Cr 上电压，驱动谐振腔正向谐振，能量经变压器送到副边，**D1 + D4** 整流给负载。

```
原边回路（正向谐振，Cr 充电）：
  Vin(+) ══> S1 ══> SW ══> Cr ══> Lr ══> Lp(原边) ══> GND ══> Vin(-)

副边回路（实测 D1、D4 导通）：
  SECA ══> D1 ══> Vout ══> Rload/Co ══> GND ══> D4 ══> SECB
```

- 谐振电流 iLr 走半个正弦（先升后降）。
- 同时励磁电流 iLm 在 +194V（=n·Vout）作用下**线性上升**。
- 实测此阶段 D1、D4 电流峰值 ≈ 4.9A，D2、D3 = 0。

```
   Vin ─[S1闭]─┐
              SW●──Cr──Lr──●──Lp──┐         ┌─D1▲─ Vout ─┐
                          (原边)   │  4:1    │            Co═ Rload
              [S2开]               └─────────┤            │
   GND ───────┘                   (副边)     └─D4▲─ GND ──┘
```

---

### 状态 ②　死区 1（3.59 ~ 3.79µs，约 200ns）　SW: 400V → 0V

S1、S2 **都断开**。此刻谐振电流 = 励磁电流（正值，约 +1.26A，副边电流已过零）。这股**电感电流不能突变**，于是给 SW 节点的结电容放电：

```
  谐振腔电流(正) ══> 抽走 SW 节点 Coss 的电荷 ══> SW 电压从 400V 跌向 0V
  当 SW 降到 0V，下管体二极管 Dls 导通钳位：
        GND ══> Dls ══> SW   （续流）
```

- SW 被 Dls 钳在 0V，**此时让 S2 开通 → 零电压开通（ZVS）**。
- 副边二极管全部关断（电流已过零 → ZCS）。

> **这是 LLC 软开关的关键瞬间**：靠励磁电流（不是负载电流）完成 SW 节点的电压翻转。所以 Lm 不能太大——必须留足够励磁电流来实现 ZVS。

---

### 状态 ③　S2 导通（低边，3.79 ~ 7.38µs）　SW = 0V

下管 S2 闭合，SW 接地。Cr 上储存的电压（此时约 286V→…）反向驱动谐振腔，能量经变压器送副边，**D2 + D3** 整流。

```
原边回路（反向谐振，Cr 放电，不经过 Vin）：
  GND ══> Lp(原边) ══> Lr ══> Cr ══> SW ══> S2 ══> GND

副边回路（实测 D2、D3 导通）：
  SECB ══> D2 ══> Vout ══> Rload/Co ══> GND ══> D3 ══> SECA
```

- 谐振电流 iLr 走负半个正弦。
- 励磁电流在 −194V 作用下**线性下降**。
- 实测 D2、D3 峰值 ≈ 4.9A，D1、D4 = 0。
- 注意这个回路**不经过输入源**——是谐振腔自身的储能在循环，这正是谐振变换的特征。

---

### 状态 ④　死区 2（7.38 ~ 7.58µs，约 200ns）　SW: 0V → 400V

S1、S2 都断开。谐振电流 = 励磁电流（负值，约 −1.26A），给 SW 节点结电容**充电**：

```
  谐振腔电流(负) ══> 给 SW 节点 Coss 充电 ══> SW 电压从 0V 升向 400V
  当 SW 升到 400V，上管体二极管 Dhs 导通钳位：
        SW ══> Dhs ══> Vin   （续流）
```

- SW 被 Dhs 钳在 400V，**此时让 S1 开通 → 零电压开通（ZVS）**。
- 回到状态 ①，循环往复。

---

### 四状态时序总览

```
  SW电压  400 ┤████████▏       ▕████████▏       ▕███   ← S1导通段=400V
              │        ▏╲     ╱▏        ▏╲     ╱
            0 ┤        ▏ ╲___╱ ▏████████▏ ╲___╱      ← S2导通段=0V
              └─①S1on─┼②─┼─③S2on──┼④─┼──①…
                      死区1       死区2
  iLr(谐振) ：正半正弦 │ ≈+Imag │ 负半正弦 │ ≈−Imag │   （连续、近似正弦）
  iLm(励磁) ：  ↗上升  │  峰+1.26│  ↘下降  │ 峰−1.26│   （三角波）
  整流导通  ： D1+D4   │  全关   │  D2+D3  │  全关  │
```

## 6. 波形数据详细分析

以下为 LTspice 稳态窗口（100µs）实测数据。

### 6.1 开关节点 V(sw) 与占空比

| 项目 | 数值 | 说明 |
|------|------|------|
| 高低电平 | 0 ~ 400V | 干净方波，被体二极管钳位（无过冲） |
| 周期 Tsw | 7.576 µs | 实测 |
| 频率 fsw | 132.0 kHz | = 1/Tsw |
| **门极占空比** | **47.4%** | 导通时间 Ton = Tsw/2 − Tdead = 3.788 − 0.2 = 3.588µs |
| 死区时间 | 200 ns ×2 | 每次换流留 200ns 防直通 |
| **SW 节点占空比** | **≈ 50%** | SW>200V 的时间实测占 50% |

> **一个易被忽略的细节**：门极信号占空比是 47.4%（两边各扣 200ns 死区），但 **SW 节点电压的占空比却是 50%**。原因：死区期间 SW 在做 ZVS 翻转（400↔0），正好在死区中点穿过 200V，所以"SW 高于中点"的时间补回了死区，仍是半周。这说明 ZVS 换流是"无缝"衔接的。

### 6.2 谐振电流 I(Lr)（= I(Lp)，原边电流）

| 项目 | 数值 |
|------|------|
| 峰值 | ± 1.70 A |
| 有效值 RMS | 1.057 A |
| 波形 | 近似正弦（rms/峰值 = 0.62，接近正弦 0.707） |
| 平均值 | ≈ 0（纯交流） |

谐振电流是**连续的近似正弦波**，这是工作在谐振点的标志。它由"方波 − Cr 电压"驱动 Lr-Cr 谐振产生。

### 6.3 励磁电流 I(Lm)（三角波）

由 `Imag = I(Lp) + I(Ls)/n` 算得：

| 项目 | 数值 |
|------|------|
| 峰峰值 | 2.52 A（± 1.26 A） |
| 波形 | **三角波**（线性充放电） |
| 斜率 | ≈ n·Vout / Lm = 194V / 300µH ≈ 0.65 A/µs |

励磁电流在原边电压被钳位（±n·Vout）期间线性变化，呈三角形。**它在开关时刻达到峰值 ±1.26A，正是这股电流完成 ZVS 翻转。**

> **谐振电流与励磁电流的关系**：在开关瞬间副边电流过零，此时 `iLr = iLm ≈ ±1.26A`（两曲线相交）；在半周中段副边传输功率，`iLr` 升到正弦峰 1.70A 而 `iLm` 还在爬。两者之差（×n）就是送往副边的电流。

### 6.4 副边电流 I(Ls) 与整流二极管

| 项目 | 数值 |
|------|------|
| 副边电流峰值 | ± 4.9 A |
| 副边电流 RMS | 2.03 A |
| 每个二极管峰值 | ≈ 4.9 A |
| 每个二极管 RMS | ≈ 1.43 A |
| 导通规律 | **S1 导通→D1+D4；S2 导通→D2+D3**（实测确认） |

副边电流也是近似正弦的半波，每半周由一对二极管接力。

### 6.5 谐振电容电压 V(Cr)

| 项目 | 数值 |
|------|------|
| 平均值 | 201 V（= Vin/2 ✓） |
| 摆动范围 | 114 ~ 286 V |
| 峰峰值 | 172 V |

Cr 电压 = **200V 直流偏置 + 谐振交流**。直流分量隔断了母线直流，交流分量参与谐振。它与谐振电流相位差约 90°（电容电压滞后电流）。

### 6.6 输出电压 V(out)

| 项目 | 数值 |
|------|------|
| 平均值 | ≈ 48.6 V |
| 开关纹波 | ≈ 150 mVpp |
| 负载电流 | 1.96 A |
| 输出功率 | ≈ 96 W |

> 注：仿真窗口里 Vout 有约 0.7V 的**缓慢漂移**，那是输出电容（47µF）与负载（25Ω，时间常数≈1.2ms）尚未完全稳定的过渡，**不是开关纹波**。真正的高频开关纹波只有约 150mV。要看完全稳态可把 `.tran` 跑到 2ms 以上。

## 7. 软开关分析：ZVS 与 ZCS

LLC 的精华在两类软开关，仿真都已验证：

### 7.1 原边 ZVS（零电压开通）—— MOSFET
- **判据**：开关管开通前，其两端电压已被拉到 0。
- **实测**：V(sw) 全程被钳在 **−0.75V ~ 400.75V**，即每次开通前都先被体二极管钳到对侧电平。
- **机理**：死区期间励磁电流（±1.26A）给 SW 结电容充放电完成翻转（见状态②④）。
- **意义**：开通损耗 ≈ 0。

### 7.2 副边 ZCS（零电流关断）—— 整流二极管
- **判据**：二极管关断时电流已自然过零。
- **实测**：在 S1 关断瞬间，副边电流 `|I(Ls)| = 0.000 A`。
- **机理**：fsw = fr 时，谐振半周 = 开关半周，副边电流正好在开关时刻走完半个正弦回到零。
- **意义**：二极管无反向恢复损耗，关断损耗 ≈ 0。

> 正是 ZVS + ZCS 同时成立，LLC 才能在高频（132kHz）下保持高效率。这也解释了**为什么必须画体二极管 Dhs/Dls 和结电容 Coss**——没有它们，死区期间 SW 节点会失去续流通路、电压飙到几十万伏（早期版本的真实教训），ZVS 也无从谈起。

## 8. 结果汇总与结论

### 8.1 关键数据一览

| 类别 | 参数 | 数值 |
|------|------|------|
| 输入输出 | Vin / Vout / Pout | 400V / 48.6V / 96W |
| 频率 | fsw / fr / Tsw | 132kHz / 132.6kHz / 7.576µs |
| 时序 | 门极占空比 / 死区 | 47.4% / 200ns |
| 原边电流 | iLr 峰 / RMS | 1.70A / 1.06A |
| 励磁电流 | iLm 峰峰 / 斜率 | 2.52A / 0.65A·µs⁻¹ |
| 副边电流 | iLs 峰 / RMS | 4.9A / 2.03A |
| 谐振电容 | Vcr 均值 / 摆幅 | 201V / 114~286V |
| 输出 | 纹波 / 负载电流 | 150mV / 1.96A |
| 软开关 | ZVS / ZCS | ✓ 原边 / ✓ 副边 |

### 8.2 结论
1. 电路工作在**谐振点**（fsw≈fr），增益≈1，输出 ~48.6V 符合设计 `(Vin/2)/n`。
2. 一个周期内电流在 **4 个状态**间流转：S1 导通正向送能（D1/D4）、死区1 完成 ZVS、S2 导通反向送能（D2/D3）、死区2 完成 ZVS。
