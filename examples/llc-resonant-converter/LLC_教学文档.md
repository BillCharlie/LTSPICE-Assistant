## 1. 这是什么电路

**半桥 LLC 谐振变换器（Half-Bridge LLC Resonant Converter）**，是开关电源里最主流的 DC-DC 拓扑之一，广泛用于服务器电源、充电器、电视电源等。

- 输入：400V 直流（典型 PFC 输出母线电压）
- 输出：约 48V / 95W
- 开关频率：132kHz（正好工作在谐振点）

它的优点是 **原边 ZVS（零电压开通）+ 副边 ZCS（零电流关断）**，开关损耗极低、效率高、EMI 小。

## 3. 电路原理与拓扑

```
                   半桥                谐振腔                 变压器 4:1        整流+滤波
   Vin=400V ──┬──[S1]──┐                                                    ┌── D1 ─┬─── Vout
              │  (上管)  │            Cr      Lr                    n:1       │       │   (48V)
              │        SW●──[Cr]──[Lr]──●NB──[Lp/Lm]══════[Ls]──●SECA──┤      Co ═╪═ Rload
              │  (下管)  │              谐振电容 谐振电感  励磁电感   变压器      │       │  (25Ω)
              └──[S2]──┘                                       ●SECB──┤  D2~D4 ┴─── GND
              │                                                        全桥整流
             GND
```

**工作过程（一个开关周期）：**
1. 上管 S1 导通 → SW 节点接到 400V，电流经 `Cr→Lr→变压器`，能量送到副边整流给负载。
2. 死区时间（200ns）→ 两管都关，谐振电流给 MOSFET 结电容充放电，把 SW 电压拉到对侧 → 实现 **ZVS**。
3. 下管 S2 导通 → SW 接地，谐振腔反向谐振。
4. 再死区 → 回到第 1 步。

**三个电感/电容的分工：**
- `Cr + Lr` 构成主谐振回路，决定谐振频率 `fr`。
- `Lm`（励磁电感）参与第二谐振点，是 LLC 比 LC 串联谐振多出来的那个"L"，让它能在轻载/宽范围调压。

谐振频率公式：

```
fr = 1 / (2π·√(Lr·Cr)) = 1 / (2π·√(60µH × 24nF)) ≈ 132.6 kHz
```

我们把开关频率设在 132kHz ≈ fr，所以电压增益≈1，是最理想的工作点。

## 4. 网表逐行讲解（核心）

打开 `LLC_converter.cir`，内容如下，逐段解释：

```spice
.param Vin=400 fsw=132k n=4 Lr=60u Cr=24n Lm=300u
.param Tsw=1/fsw Tdead=200n
```
> 定义参数。`n=4` 是变压器匝比，`Tsw` 是开关周期，`Tdead` 是死区时间。用 `.param` 的好处是改一个数全局生效。

```spice
Vbus VIN 0 {Vin}
```
> 400V 直流输入母线（VIN 节点对地）。

```spice
S1 VIN SW GH 0 MSW
S2 SW  0  GL 0 MSW
.model MSW SW(Ron=0.05 Roff=1Meg Vt=2.5 Vh=0)
```
> 半桥两个开关，用**理想压控开关**代替 MOSFET（仿真快、看原理清楚）。S1 接在 VIN 和 SW 之间（上管），S2 接在 SW 和地之间（下管）。`GH/GL` 是各自的栅控电压，超过 `Vt=2.5V` 就导通。

```spice
Dhs SW VIN DBODY
Dls 0  SW  DBODY
.model DBODY D(Ron=0.02 Roff=1Meg Vfwd=0.7)
```
> **体二极管（反并联二极管）**。这是关键！死区期间两管都关，谐振电流必须有续流通路，否则 SW 节点电压会飙到几十万伏（理想开关没有体二极管）。它同时提供 ZVS 的续流路径，把 SW 钳位在 0~400V。

```spice
Coss1 VIN SW 150p
Coss2 SW 0   150p
```
> MOSFET 的输出结电容，帮助 ZVS 软开关过渡。

```spice
Vgh GH 0 PULSE(0 5 0       5n 5n {Tsw/2-Tdead} {Tsw})
Vgl GL 0 PULSE(0 5 {Tsw/2} 5n 5n {Tsw/2-Tdead} {Tsw})
```
> **互补栅极驱动**。两路 50% 占空比方波，相位差半个周期，各留 200ns 死区。`PULSE(初值 高值 延迟 上升 下降 高电平时间 周期)`。

```spice
Cr SW NA {Cr}
Lr NA NB {Lr}
Lp NB 0  {Lm}
```
> 谐振腔：谐振电容 `Cr` → 谐振电感 `Lr` → 励磁电感 `Lp`（也是变压器原边）。

```spice
Ls SECA SECB {Lm/(n*n)}
K1 Lp Ls 0.9999
```
> 变压器副边绕组 + 耦合系数。副边电感 = 原边/匝比² = `Lm/16`。`K1` 把原副边耦合起来（0.9999≈理想变压器）。

```spice
D1 SECA VOUT DMOD
D2 SECB VOUT DMOD
D3 0    SECA DMOD
D4 0    SECB DMOD
.model DMOD D(Ron=0.02 Roff=1Meg Vfwd=0.55)
```
> 副边**全桥整流**，4 个二极管把交流整成直流。

```spice
Co VOUT 0 47u IC=48
Rload VOUT 0 25
```
> 输出滤波电容（`IC=48` 设初值 48V，让仿真更快进入稳态）+ 负载电阻 25Ω（约 95W）。

```spice
.tran 0 300u 200u 20n uic
```
> 瞬态仿真指令：跑到 300µs，从 200µs 开始保存数据（跳过启动过程），最大步长 20ns，`uic` 用初始条件启动。

## 5. 自主复现步骤（重点）

### 方法 A：直接看我跑好的结果（最快）

1. 打开 LTspice。
2. 菜单 **File → Open**，文件类型选 "All files" 或直接在文件名框输入：
   ```
   LLC_converter.cir
   ```
3. 按工具栏的 **绿色 ▶ Run 按钮**（或菜单 Simulate → Run）。
4. 因为同目录有 `LLC_converter.plt`，LTspice 会**自动显示**我配好的波形：上窗格 V(sw)+I(Lr)，下窗格 V(vout)。

> 如果没自动显示波形，按下面"方法 B"的第 4 步手动加。

### 方法 B：从零自己加波形

1~3 步同上。运行后波形窗口是空的黑框，然后：

4. 在波形窗口空白处**右键 → Add Trace**（或菜单 **Plot Settings → Add trace**，快捷键 `A`）。
5. 在弹出的 "Add Traces to Plot" 对话框里，在底部 **Expression(s) to add** 框输入：
   ```
   V(sw) I(Lr)
   ```
   点 OK。LTspice 自动把电压放左轴、电流放右轴。
6. 想再加一个窗格看输出电压：菜单 **Plot Settings → Add Plot Pane Below**（快捷键 `B`），点一下新的空窗格，再 **Add trace** 输入 `V(vout)`。
7. 想保存这套显示：**Plot Settings → Save Plot Settings As**，存成 `LLC_converter.plt`，下次自动加载。

### 还能直接点波形节点

运行后，把鼠标移到网表里的节点名上（或在原理图里点导线），光标变成红色电压探针，**左键点一下**就把那个节点电压加到波形里——这是 LTspice 最直观的看波形方式。

## 6. 波形怎么看

| 信号 | 颜色（默认） | 看什么 |
|------|------|--------|
| `V(sw)` | 绿 | 开关节点，0→400V 干净方波 = ZVS 成功（边沿被体二极管钳住） |
| `I(Lr)` | 蓝 | 谐振电流，近似正弦，峰值 ±1.45A |
| `V(vout)` | 红 | 输出电压，约 48.6V，纹波约 150mV |

**怎么判断 ZVS 成功？** 看 V(sw) 上升沿——如果是先慢慢爬升再被钳住（而不是瞬间跳变 + 尖峰），说明 MOSFET 是在零电压下开通的。

**怎么测数值？** 在波形窗口点信号名（如顶部的 `V(sw)` 标签），出现光标，可读出精确值；按住左键拖一段，状态栏显示这段的平均值、峰峰值、RMS。

## 8. 参数调一调，看现象

在 `.cir` 顶部那行 `.param` 改数值，重新 Run：

| 改什么 | 现象 | 原理 |
|--------|------|------|
| `fsw` 从 132k **调高**到 150k、180k | 输出电压**下降** | 频率高于 fr，增益<1（降压区） |
| `fsw` 从 132k **调低**到 110k、90k | 输出电压**上升** | 频率低于 fr，进入升压区，靠 Lm 第二谐振 |
| `Rload` 从 25 改到 5（重载）/ 100（轻载） | 看调压能力和电流变化 | LLC 轻载调压难，是它的难点 |
| `n` 从 4 改成 5 | 输出电压下降到约 40V | 匝比越大，副边电压越低 |

**进阶玩法 —— 扫频画增益曲线（谐振曲线）：**
把 `.param fsw=132k` 那行注释掉，改用：
```spice
.step param fsw 80k 200k 5k
```
就能一次跑出不同频率下的输出，画出 LLC 经典的"增益 vs 频率"曲线。

## 9. 我是怎么做出那张彩色图的

聊天里那张漂亮的彩色波形图**不是** LTspice 截图，是这么来的：

1. 用命令行让 LTspice **批处理跑仿真**（不开界面）：
   ```
   LTspice.exe -b -Run LLC_converter.cir
   ```
   `-b` = batch 模式，生成 `LLC_converter.raw`（真实仿真数据）。
2. 用 Python 脚本 `parse_raw.py` 解析二进制 `.raw` 文件，提取各信号。
3. 用 `export.py` 导出成 `wave.csv`。
4. 把 CSV 数据喂给图表工具重新绘制。

**所以数据是 LTspice 真算的，只是展示的图我用 Python 重画美化了。** 而本节第 5 步教你看的，才是 100% LTspice 原生波形界面。

## 10. 可视化原理图（.asc）

网表（`.cir`）是文字描述，原理图（`.asc`）是图形化的同一个电路。我已经把网表转成了 LTspice 原理图，**双击即可看到画好的电路图**：

- **`LLC_converter_wired.asc`** —— 全导线版（推荐），元件之间用真实导线连接，像教科书电路图。
- `LLC_converter.asc` —— 网络标号版，用相同名字的节点标号代替部分连线（工程师画复杂图常用）。

两版电气完全等价，运行后波形与网表一模一样（已逐一验证）。

### 怎么打开
直接双击 `.asc` 文件，或在 LTspice 里 **File → Open**，文件类型保持默认（`*.asc`）即可看到。打开后按绿色 ▶ Run，同目录的 `.plt` 会自动显示 V(sw)/V(vout)/I(Lr)。

### .asc 文件是怎么编码电路的
`.asc` 是纯文本，靠坐标描述图形。三类关键语句：

| 语句 | 含义 | 例子 |
|------|------|------|
| `WIRE x1 y1 x2 y2` | 一段导线（连接两个坐标点） | `WIRE 336 256 336 352` |
| `FLAG x y 名字` | 节点标号；`0` 是接地符号 | `FLAG 200 128 VIN` / `FLAG 48 272 0` |
| `SYMBOL 元件 x y 方向` | 放一个元件（R0/R180 是旋转角） | `SYMBOL ind2 656 504 R0` |
| `SYMATTR InstName/Value` | 元件名 / 参数值 | `SYMATTR Value {Cr}` |
| `TEXT x y Left 2 !指令` | SPICE 指令（`!`开头）或注释（`;`开头） | `!.tran 0 300u 200u 20n uic` |

> **手工画 .asc 的关键**：每个元件符号的引脚有固定坐标偏移，导线端点必须精确落在引脚上才算连上。例如 `cap`（电容）引脚在 (16,0) 和 (16,64)，`diode` 在 (16,0)/(16,64)，`sw`（开关）功率脚在 (0,16)/(0,96)、控制脚在 (-48,80)/(-48,32)。本图里整流二极管用 `R180` 旋转 180°，让箭头朝输出方向。

### 验证方法（为什么敢说接线正确）
判断原理图对不对，最硬的标准是 **能不能跑出和网表相同的结果**。我对两版 `.asc` 都按了 Run，得到的 V(sw)、I(Lr)、V(vout) 与 `.cir` 完全一致 —— 这就证明每一根导线都连对了。

## 11. 常见问题

**Q: 打开 .cir 时文件列表里看不到？**
A: 打开对话框默认只显示 `.asc`（原理图）。在文件名框直接敲完整路径 `LLC_converter.cir` 就能打开；或把文件类型下拉改成 "All Files (*.*)"。

**Q: 运行报错或波形是直线？**
A: 检查 `.param` 那两行有没有被改坏；确认 `.tran` 指令还在。本网表已验证可正常运行（见 `LLC_converter.log`，0 错误）。

**Q: 想换成真实 MOSFET 而不是理想开关？**
A: 把 `S1/S2` 换成具体型号（如 `M1 VIN GH SW SW Si7850`），并加上对应的 `.model` 或库文件。理想开关版本更适合理解原理，真实器件版本更适合算损耗和效率。

**Q: 输出电压一直在缓慢漂移没稳住？**
A: 那是输出电容 47µF 与负载 25Ω 的时间常数还没走完（约 1ms）。把 `.tran` 的终止时间加大（如跑到 2m），或加大 `IC` 初值即可看到完全稳态。
