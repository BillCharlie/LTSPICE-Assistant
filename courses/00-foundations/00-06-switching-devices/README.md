# 00-06 开关器件：理想开关 → Si MOSFET → GaN HEMT

**状态**：⬜ 未开始　|　**前置**：00-05　|　**预计时长**：2.5 h

## 学习目标
- 用理想开关模型理解拓扑，再逐步加上真实寄生（Rdson、Coss、Qg、体二极管）
- 开关的四个工作象限与反向导通
- Si MOSFET 与 GaN HEMT 的关键差异：无体二极管的反向导通、Qrr≈0、Coss 更小但非线性更强
- 建立后续所有课程要用的开关模型库
