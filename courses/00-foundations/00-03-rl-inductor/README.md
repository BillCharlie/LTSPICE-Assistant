# 00-03 RL 与电感：伏秒平衡的雏形、续流路径

## 学习目标
- 电感的核心性质：电流不能突变、v = L·di/dt
- 推出 RL 的一阶响应与 τ=L/R
- **为什么开关断开电感会产生高压**，续流二极管为什么是必需品（这是所有开关电源的地基）
- 首次引入"伏秒平衡"：稳态下电感一周期内的电压积分必须为零
