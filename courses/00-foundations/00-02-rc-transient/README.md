# 00-02 RC 充放电：时间常数与一阶微分方程

**状态**：⬜ 未开始　|　**前置**：00-01　|　**预计时长**：2 h

## 学习目标
- 从 KCL 推出 RC 电路的一阶微分方程，并解出指数曲线
- 理解时间常数 τ=RC 的物理意义（63% / 5τ 稳定）
- 电容的核心性质：电压不能突变、"安秒平衡"的雏形
- 用仿真测出 τ 并与手算对照
