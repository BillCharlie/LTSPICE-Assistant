# 00-05 频域分析：滤波器、谐振与 Q 值

**状态**：⬜ 未开始　|　**前置**：00-04　|　**预计时长**：2.5 h

## 学习目标
- `.ac` 分析怎么用，波特图（幅频/相频）怎么读
- RC 低通的截止频率、-20dB/dec 斜率的来源
- LC 二阶系统：谐振频率、Q 值、阻尼比、过冲与振铃
- 为什么开关电源的输出 LC 滤波器天生是个二阶欠阻尼系统（为后面闭环补偿埋伏笔）
