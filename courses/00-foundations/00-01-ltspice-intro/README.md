# 00-01 LTspice 入门与 KVL/KCL 仿真验证

**状态**：⬜ 未开始　|　**前置**：无　|　**预计时长**：1.5 h

## 学习目标
- 看懂 LTspice 的三种基本分析：`.op`（直流工作点）、`.dc`（扫描）、`.tran`（时域）
- 用仿真亲手验证你已经会的 KVL / KCL 与分压公式
- 学会本仓库的无头工作流：写 .cir → 跑仿真 → 从 .raw 读数字
- 学会看 .log 判断仿真有没有真的收敛

## 本课交付物（完成后本文件夹应有）
- `讲义.md` —— 物理直觉 → 数学推导 → 设计公式与计算要点（附录含完整推导）
- `*.cir` —— 可无头运行的 netlist，所有数值为 `.param`
- `*.asc` / `*.plt` —— 可在 LTspice 打开并按 Run 的全接线原理图 + 预设波形
- `波形分析.md` —— 波形逐条解读 + 手算 vs 仿真实测对照表
- `练习.md` —— 参数实验 + 计算题（含答案）
- `data/` —— `.raw` / `.log` / 导出的 csv
