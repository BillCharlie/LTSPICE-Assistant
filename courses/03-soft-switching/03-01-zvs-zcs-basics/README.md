# 03-01 软开关原理：ZVS / ZCS 的能量账

**状态**：⬜ 未开始　|　**前置**：02-05　|　**预计时长**：3 h

## 学习目标
- 硬开关的损耗来自哪里：V-I 交叠区的面积
- ZVS 的条件：½·L·I² > ½·Coss·V²，并推出所需死区时间
- ZCS 的条件与适用器件
- **GaN 重点课**：Coss 非线性与 Eoss，为什么 GaN 的 ZVS 更容易也更关键
