# 02-02 反激变换器 Flyback（DCM / CCM / RCD 钳位）

**状态**：⬜ 未开始　|　**前置**：02-01　|　**预计时长**：3.5 h

## 学习目标
- Flyback 本质是"隔离的 Buck-Boost"：推出 M = (D/(1-D))·(Ns/Np)
- DCM 与 CCM 的选择与设计公式
- 漏感能量去哪了：RCD 钳位电路的设计与损耗
- 峰值电流、RMS 电流与变压器设计要点
