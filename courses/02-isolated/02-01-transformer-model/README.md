## 学习目标
- 理想变压器 → 磁化电感 → 漏感的逐层建模
- LTspice 的 `K` 语句怎么写，耦合系数 k 与漏感的关系
- 匝比、伏秒、磁通密度 B 与磁芯饱和
- 同名端（dot convention）的物理意义与仿真中的验证方法
