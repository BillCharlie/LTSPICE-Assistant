# 04-01 功率因数校正 PFC 与 CCM Boost PFC

**状态**：⬜ 未开始　|　**前置**：03-04　|　**预计时长**：3.5 h

## 学习目标
- 为什么整流+电容会导致 PF 极差、谐波超标（画出尖峰输入电流）
- PFC 的目标：让输入电流跟随输入电压正弦
- 平均电流控制的双环结构（电流内环 + 电压外环）
- 母线电容与二倍工频纹波的计算
